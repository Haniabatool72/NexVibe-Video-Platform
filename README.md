# 🎬 NexVibe — Video Streaming Platform

> **Watch what's next.**

NexVibe is a modern, responsive video streaming web application inspired by popular video platforms. It combines a premium streaming experience with video discovery, search, subscriptions, playlists, watch history, authentication UI, custom video playback, Supabase integration, and optional live YouTube data.

Built with a modern dark-first interface and responsive design for desktop, tablet, and mobile devices.

## 🔐 Backend & Integrations

NexVibe includes **Supabase integration** for backend and authentication capabilities.

### Supabase

- Supabase JavaScript client
- Authentication integration
- User account handling
- Backend-ready architecture

### YouTube Data API v3

When a valid API key is provided, NexVibe can retrieve:

- Live search results
- Trending videos
- Channel information
- Channel videos
- Subscriber information

If no API key is configured, the application can run using curated demo content.

### YouTube IFrame API

Used for:

- YouTube video playback
- Video player integration
- Playback controls
- YouTube streaming support
